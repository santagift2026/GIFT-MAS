GIFTMAS WEBSITE PACKAGE

Contents
- index.html: the Giftmas single-page website (HTML, CSS, and JavaScript in one file).

Run locally
1. Extract this ZIP file.
2. Open index.html in a modern browser.

Publish as a static website
- Upload index.html to a static hosting provider such as Netlify Drop or GitHub Pages.
- This package does not include hosting credentials, a domain, or deployment configuration for a specific provider.

Important project status
- Giftmas token is a concept; no token deployment or mint address is verified.
- Mainnet gifting and GFTM token transfers are disabled.
- The included optional SOL transfer code targets Solana Devnet only. It has not been end-to-end tested in a real browser/wallet environment. Use only test SOL with no intended monetary value and review the code before use.
- The page loads @solana/web3.js from unpkg at runtime, so an internet connection is needed for the Devnet test-transfer feature.
- The website is not publicly hosted by this ZIP package.
